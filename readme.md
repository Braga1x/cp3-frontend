

> **Nexus Games** é um projeto de e-commerce focado em hardware e periféricos de alta performance. Com uma estética cyberpunk minimalista, o site oferece uma experiência de navegação fluida, responsiva e moderna.

---

## 🎯 Sobre o Projeto

Este projeto foi desenvolvido como requisito para o **Checkpoint 3** da disciplina de **Frontend** no curso de Engenharia de Software da FIAP. O objetivo principal foi criar uma landing page completa (Loja Gamer), implementando conceitos de semântica web, estilização avançada com CSS (Flexbox/Grid) e manipulação dinâmica do DOM com JavaScript.

### 🌟 Principais Funcionalidades

- **Design Responsivo:** Layout que se adapta perfeitamente a smartphones, tablets e desktops.
- **Estrutura Semântica:** Código HTML5 organizado e acessível (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **Interatividade:** Simulação de adição de itens ao carrinho com feedback visual.
- **Validação de Contato:** Formulário de contato com validação básica e mensagem de sucesso dinâmica.
- **Identidade Visual Premium:** Paleta de cores focada no contraste entre grafite escuro, cinza-claro e vermelho vinho.
